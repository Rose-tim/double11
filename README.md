# 双11狂欢购物节 — 前端网页设计作品

## 项目简介
围绕"双十一购物节"主题开发的纯前端电商促销网页，使用原生 HTML + CSS + JavaScript 实现，无需任何构建工具，双击 `index.html` 即可在浏览器中打开运行。

## 目录结构
```
double11-shopping-festival/
├── index.html              # 页面入口（HTML结构）
├── css/
│   ├── reset.css           # 浏览器默认样式重置
│   ├── style.css           # 主样式（双11红橙主题、布局、组件）
│   └── responsive.css      # 响应式适配（手机/平板/桌面）
├── js/
│   ├── data.js             # 商品/秒杀/优惠券 静态数据
│   ├── countdown.js        # 双11活动倒计时
│   ├── product.js          # 优惠券/秒杀/商品列表 渲染与筛选
│   ├── cart.js             # 购物车增删改、满减计算、抽屉面板
│   └── main.js             # 程序入口、Toast、导航交互
├── assets/
│   └── images/             # 图片资源目录（演示用占位）
└── README.md               # 项目说明
```

## 核心功能
1. **活动倒计时**：实时显示距双11开抢的天/时/分/秒
2. **领券中心**：满300减50等4档优惠券，点击领取后状态切换
3. **限时秒杀**：4款秒杀商品，含抢购进度条
4. **分类筛选**：数码/美妆/服饰/食品/家居 6个分类切换
5. **购物车系统**：加入购物车、数量加减、删除、合计金额、满300减50自动计算
6. **响应式适配**：桌面4列 → 平板3列 → 手机2列/1列，移动端汉堡菜单
7. **导航高亮**：滚动时自动高亮当前所在板块

## 技术要点
- 原生 JavaScript（IISE 模块化），无任何框架依赖
- CSS Flex + Grid 布局，`var()` 统一配色变量
- 商品数据与渲染逻辑分离，便于维护
- 核心逻辑处均有中文注释

## 运行方式
直接双击 `index.html`，或在浏览器中打开即可。
